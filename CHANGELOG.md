# Changelog

All notable changes to this project are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- README with screenshots, contributing guide, issue and pull request templates.

### Fixed
- Resource bars in the party card are aligned even when resource names have different lengths.

## 2026-10-20

### Added
- Several campaigns in the same browser, each with its own map, tables, session log and party.
- Linking a campaign to a `.campagna.json` file with automatic saving (Chrome, Edge); open and download as fallback.
- Game profiles per campaign (B/X · OSE, D&D 5e, Call of Cthulhu 7e, Mörk Borg, generic) with editable
  resources, ability scores, stats, saving throws, conditions, currencies and labels.
- Free dice roller and party-wide recovery written to the session log.
- Campaign configurator: campaign details, character sheets, hirelings, party supplies, NPCs, factions,
  quests and tools (experience split, rest, initiative, reaction, morale).
- Party card on the main screen with hit-point bars and the dungeon turn counter.

### Changed
- Data from the single-campaign version is converted automatically on first start.

## 2026-10-20 — first version

### Added
- Hexcrawl map, weighted random tables, time and weather, session log, Launchpad support.
